# SmartBudgetSite Backups

SmartBudgetSite Backups is a private operational integration
used by the SmartBudgetSite administrator to maintain
encrypted off-site backups.

The application uses rclone and the Google Drive API
with limited file-level access.

It is not a customer-facing service and does not
provide public registration or sign-in.
